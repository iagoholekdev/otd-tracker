OTD Tracker

Compara PBIs fechados com o Target Date pra saber quem entregou no prazo e quem furou. Roda local — na tua máquina — e conversa direto com o Azure DevOps da tua organização.

Baixar

Escolhe teu sistema. Depois de baixar, dá permissão de execução (Linux/Mac) e roda — abre em http://localhost:8080.

Como rodar

  • Baixa o binário do teu sistema acima
  • Linux/Mac: no terminal, chmod +x otd-tracker-* e depois ./otd-tracker-*
  • Windows: dá duplo-clique no .exe (o Windows pode avisar que é de um "editor desconhecido" — clica em "Mais informações → Executar assim mesmo")
  • Abre http://localhost:8080 no navegador
  • Preenche organização, projeto e o teu Personal Access Token
ℹ️
Por que não dá pra usar direto aqui nessa página?
O Azure DevOps bloqueia chamadas de API vindas de outros domínios (CORS). Pra consultar teus work items com segurança — sem expor teu PAT pra nenhum servidor de terceiro — a ferramenta roda um pequeno servidor local que fala com o Azure DevOps diretamente da tua máquina.
